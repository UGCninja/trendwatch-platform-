▸ How is this determined?
Language — we analyze the comment text and detect the language it's written in. This is exact data.

Country — we don't know where the person is from. We make an assumption: if someone writes in Tagalog — most likely from the Philippines, in Albanian — from Albania. This is a rough estimate, not a fact.

English is not shown in countries — people write in English from all over the world, so it can't be linked to one country.
